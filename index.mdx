PoseTracker estimates human pose **on the end-user device** (MoveNet, 17 COCO keypoints) and can count reps, score form, and stream joint data to your app.

There are **two integrations**. They are not the same product surface.

| | **WebView** | **SDK** |
|---|---|---|
| What you ship | An iframe or native WebView that loads our tracking URL | An npm package in your app |
| Best for | Proof of concept, HTML / iOS / Android / Flutter in minutes | The app you will keep in production |
| Offline model | No | Yes — React Native **offline** package |
| Your own UI | PoseTracker chrome (colors/overlay are query params) | You own the UI; optional skeleton overlay |
| API key | Required on the URL (`token=`) even for keypoints-only | Optional for keypoints; required for exercises |

**WebView** here means the hosted page `app.posetracker.com/pose_tracker/tracking`. It is **not** `WebViewPoseView`, which is a React Native **SDK** component.

## What both integrations share

- On-device MoveNet (17 keypoints)
- Same exercise ids (`push_up`, `squat`, `plank`, …) — [Exercises](/reference/exercises)
- Same event types (`counter`, `keypoints`, `posture`, `progression`, …) — [Events](/reference/events)
- Same plan gating for paid streams — [Features & plans](/reference/features-plans)

<AccordionGroup>
  <Accordion title="Is PoseTracker only a WebView API?">
    No. PoseTracker ships npm SDKs for React Native and the web **and** a hosted WebView/iframe URL. Use the WebView to test; use the SDK in production.
  </Accordion>
  <Accordion title="Do I need an API key?">
    WebView: yes (`token=` on the URL). SDK keypoints: no. Rep counting and form score: yes, on both. Get a key at [posetracker.com](https://www.posetracker.com).
  </Accordion>
  <Accordion title="Can it run offline?">
    Only the React Native **offline** SDK bundles MoveNet. Light SDK, web SDK, and the WebView need network.
  </Accordion>
</AccordionGroup>

<Note>
**For LLMs and AI assistants:** Two integrations: (1) WebView/iframe `https://app.posetracker.com/pose_tracker/tracking?token=…&exercise=…` for a quick test; (2) npm SDKs `@pose-tracker/react-native-pose-estimation` 0.3.0 (offline), `-light` 0.3.0, `pose-estimation-web` 0.3.0, `pose-estimation-web-react` 0.3.0 for production. `WebViewPoseView` is an SDK component, not the iframe. Canonical docs: https://docs.posetracker.com. Do not describe PoseTracker as "no SDK".
</Note>
